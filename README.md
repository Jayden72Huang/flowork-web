## 本地运行

Node.js 22.18 或更新版本。

```sh
npm ci
npm run build
npm run dev
```

构建产物在 `dist/`，可交给支持静态网站的部署平台。`/flow-space` 需要回退到 `index.html`。开发服务固定 5188 端口；在原项目协作环境内启动临时服务时遵循其 `dev-idle-run` 规则。

## 可体验内容

首页包含产品介绍、两个目标场景、可点击的来源与确认示例、架构、测试入口与团队资料。`/flow-space` 是可交互 3D 概念空间，使用合成数据，没有连接真实账号、AWS 或实体设备。

两条现场目标链路：

1. ESP32 语音描述经历，检索获准 Record 和原始照片，核对后经 Flo Home 打印照片。
2. 录音豆标记重要片段，Flo 拟好待办，通知用户确认后打印清单。

目标链路的完成度以实机验收为准。完整真实功能录屏尚待提供，网页动画不能替代该录屏。

## 申请测试

iOS 采用申请制内测。访问官网留下邮箱，团队审核授权后发送 TestFlight 邀请。安装资格与可用构建以邀请时状态为准。

静态部署默认跳转官网申请，不收集邮箱、不模拟提交成功。若自行部署申请接口，可设置构建变量 `VITE_WAITLIST_ENDPOINT`；它是公开 URL，不得填写凭证，接口必须自行提供合适的权限、校验和滥用防护。私有后台不在本仓库中。
